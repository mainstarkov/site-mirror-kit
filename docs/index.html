Site Mirror Kit

Утилита сохраняет доступные браузеру ресурсы сайта и позволяет открыть архив через локальный сервер.

Что умеет проект

  • Сохраняет браузерные ответы и снимки страниц.
  • Создаёт манифест ресурсов, статусов и файлов.
  • Может открыть архив локально после записи.

Требования. Node.js 22+, npm и Chromium или установленный Google Chrome.

macOS

Подготовить Терминал

Установите Node.js для macOS.

Терминал
node --version

Скачать проект

Терминал
git clone https://github.com/mainstarkov/site-mirror-kit.git
cd site-mirror-kit

Или скачайте ZIP, распакуйте и откройте терминал в папке site-mirror-kit-dev.

Запустить

Терминал
npm ci
npm run setup
node src/cli.js capture "https://example.com/" --out captures/example --serve

Для повторного запуска остановите предыдущий сервер через Ctrl+C. Для нового захвата выберите новый каталог --out.

Дополнительная команда или проверка

Терминал
node src/cli.js serve captures/example

Как проверить результат

Тест из репозитория использует локальные страницы и проверяет, что архив открывается после остановки источника. Команды записи и повторного просмотра приведены ниже.

Адрес и режим работы. Архив открывается на http://127.0.0.1:4173. Порт меняется через --port.

Исходники. src/cli.js — команды, src/index.js — запись и воспроизведение, test/ — интеграционная проверка.
