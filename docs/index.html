site-mirror-kit

Save browser-visible website resources and replay them on localhost

Локальный запуск

npm ci
npm run setup
npm link
site-mirror capture https://example.com/ --out captures/example --serve

Сохранённая копия: http://127.0.0.1:4173.

Пример работы

Архив содержит manifest.json, загруженные ресурсы и DOM-снимки.
